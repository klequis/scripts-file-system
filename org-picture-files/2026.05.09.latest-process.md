## What each script does

### `analyze-pictures.js`

1. **Scan the drive** — recursively walks `orig/` skipping: `.Trash-1000`, `.dtrash`, and the 5 direct-copy directories (`daniel/`, `dev-images/`, `Scanned Pictures/`, `2022.sophie-slide-show/`, `of-daniel.tmp/`). Counts included vs excluded files and checks against `EXPECTED_TOTAL`.
2. **Write file list** — saves the list of included paths to `<output>.filelist` (used to resume if interrupted).
3. **Build sidecar lookup** — scans the full file list and builds two maps: (a) `dir + stem → file_id` for matching `.xmp`/`.nksc` to their image, (b) `dir + DSC####number → file_id` for matching `.wav` audio notes to their NEF.
4. **Process each file** — for each file:
   - Gets file size
   - If it's a sidecar (`.xmp`/`.nksc`): looks up its paired image's `file_id` → writes to `sidecar_file` column
   - If it's a `.wav`: extracts `DSC####` token → looks up paired NEF → writes to `wav_file` column
   - If it's an image format: reads EXIF `DateTimeOriginal` for date + time
   - Fallback if no EXIF: tries date from filename → folder name → ancestor folder names → `unknown`
   - Saves one CSV row, saves checkpoint
5. **Work/rest cycle** — every 5 minutes pauses and waits for drive to cool to ≤42°C. Aborts immediately if drive hits 50°C.
6. **Output** — writes `<output>.csv` with columns: `file_id, folder_name, file_name, full_path, date, date_source, time, sidecar_file, wav_file, size_mb`. Prints date-source and EXIF stats.

---

### `generate-manifest.js`

1. **Read scan CSV** — loads `test-output-N.csv` (all 36K+ rows).
2. **Group files by date** — groups all non-sidecar files by date bucket. Calculates total size per date; if a date exceeds 500 MB, splits it into time sub-buckets.
3. **Compute destination paths** — for each file, builds the `new_path` under `new/photos/`, `new/videos/`, or `new/other/` depending on extension. Sidecars go into the same folder as their paired image.
4. **Compute new filenames** — inserts `_HH-MM-SS` into the stem of every file that has a time. Detects collisions (same name in same folder) and appends `-1`, `-2`, etc.
5. **Write copy-manifest.csv** — one row per file with: `file_id, orig_filename, new_filename, orig_path, new_path, size_bytes, status=pending`.

---

### `copy-by-date.js` (copy mode)

1. **Read manifest** — loads all rows from `copy-manifest.csv` into memory.
2. **Count pending** — reports how many files remain to copy (skips rows with `status=copied` or `failed`).
3. **Start temperature monitor** — background check every 30 seconds; warns at 45°C, sets abort flag at 50°C.
4. **Copy loop** — for each `pending` row:
   - Creates destination directory if needed
   - Copies file from `orig_path` to `new_path`
   - Sets `status = copied` (success) or `status = failed` (error, prints message)
5. **Periodic save** — writes manifest back to disk every 50 files and on every rest/abort.
6. **Work/rest cycle** — after 5 minutes of copying, waits for drive to cool; on abort flag, saves and waits immediately.
7. **Summary** — prints copied / failed / still-pending counts. On clean completion, prompts to run `--verify`.

---

### `copy-by-date.js --verify`

1. **Read manifest** — loads all rows.
2. **Check each `copied` row** — stats the file at `new_path`; checks it exists and that `size` matches `size_bytes` from the manifest.
3. **Report** — prints any `MISSING` or `SIZE-MISMATCH` lines, then summary counts (OK / missing / size mismatch / not-yet-copied).

---

### `check-manifest.js` (optional, run before copying)

1. **Blank path check** — flags any rows missing `orig_path` or `new_path`.
2. **Prefix check** — confirms every `new_path` starts with `new/` on the correct drive.
3. **Category breakdown** — counts rows per top-level dest folder (`photos/`, `videos/`, `other/`).
4. **Collision sample** — shows the first 20 collision groups (files that got a `-1`/`-2` suffix) with their original filenames so you can confirm they're genuinely different files.
5. **unknown/ sample** — shows 10 example rows destined for `unknown/` so you can judge whether the fallback dating is acceptable.

---

### `compare-orig-new.js` (optional, run after copying)

1. **Manifest file check** — for every `status=copied` row, stats the file at `new_path` and confirms size matches `size_bytes`. Reports missing and size-mismatch files.
2. **Direct-copy dir check** — for each of the 5 direct-copy dirs, walks both `orig/<dir>` and `new/<dir>` and compares file counts and sizes.
3. **Total count** — reports total files in `new/` vs expected (manifest copied + direct-copy dirs).
4. **Orphan check** — finds any files in `new/` not accounted for by the manifest or direct-copy dirs.
